## 推荐验证顺序

1. 导入备份并确认原理图与 PCB 的版本一致。
2. 根据被测器件数据手册核对 G/D/S 引脚，检查网络、丝印与实际焊接位置。
3. 检查电源及电容选型，再确认控制输入极性与继电器常开/常闭触点。
4. 先在无偏置情况下逐路做连续性测试，形成每种模式的接线表与控制状态表。
5. 完成 ERC/DRC，随后按确认后的硬件规格执行测量和校准，记录条件与结果。

验证时应记录板卡版本、仪器设置、测试条件和结果。
