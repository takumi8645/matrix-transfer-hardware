# 硬件说明

## 范围

项目名称沿用工程标题 Matrix_Transfer。硬件作为仪器与被测 MOSFET 之间的通路切换板，连接外部控制模块、测量端口和被测器件。仪器控制、自动扫描与数据显示属于整套系统背景，不作为本仓库已经交付的软件功能。

## 模块

继电器矩阵、光耦输入、达林顿阵列驱动、隔离电源、STM32 排针接口及仪器侧四端连接组成主要硬件。具体型号与位号见 `hardware/bom/bom.csv`。该表记录 PCB 器件库与原理图实例属性，采购前需结合实际选型核对。

## 接线原则

G、D、S 分别表示栅极、漏极、源极。H_CUR/H_POT/L_CUR/L_POT 是仪器四端接口，不能依据名称直接推断其在各模式下对应的 MOSFET 引脚。连接关系应依据最新原理图、实际器件引脚定义与板卡连续性测试确认。

各测量模式的通路由继电器触点状态决定。制板与装配资料从 PCB 工程导出。

## 指标表述

技术文档提到 10 kHz–1 MHz、AC 10–500 mV、漏源偏置 0–100 V。这些数值为系统设计目标，性能验证需记录仪器配置、装配器件、校准方法和测量结果。
