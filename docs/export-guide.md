# 生产资料导出说明

硬件使用嘉立创 EDA 专业版设计，工程保存版本为3.2.91。

准备生产资料时，在 EDA 中检查原理图、PCB、器件库和封装，并运行 ERC/DRC。采购和装配前核对 BOM 中的型号、封装和额定参数。

| 文件 | 用途 |
|---|---|
| 原理图 PDF | 查看完整接线 |
| PCB 正反面预览 | 展示布局与丝印 |
| BOM CSV | 采购与装配 |
| Gerber 与钻孔 | 制板 |
| 贴片坐标 | 贴片装配 |
| 实物照片 | 展示焊接后硬件 |

Gerber、钻孔和贴片坐标等生产资料从 CAD 工程导出。设计图片用于说明；实物照片应对应板卡版本。
